# SAAへの道 — 先行学習版の使い方

この版はAWS全体像・IAMの **2章6レッスン、基礎問題20問、用語21件** を収録しています。SAA試験の全範囲を網羅する完成教材ではありません。

## まずiPhoneで読む：電子書籍

1. このフォルダーの `SAA-starter.epub` をiPhoneへ保存します。OneDriveが同期済みなら、iPhoneのOneDriveから同じフォルダーを開けます。同期状況は未確認です。
2. EPUBの共有メニューから「ブック」を選びます。表示されない場合は、いったん「ファイル」に保存してから共有メニューを開きます。
3. 「ブック」で目次と本文が表示されることを確認します。
4. 機内モードにして、本文・問題・解説を読めることを確認します。

EPUBの内部構造は検証しますが、iPhoneの「ブック」での実機表示はまだ未確認です。電子書籍には自動採点と回答履歴はありません。問題の「解説へ」で答え合わせをします。公式出典リンクだけは通信が必要です。

`SAA-starter.html` は同じ内容の単一HTMLです。PCのブラウザーでファイルを直接開いて読めます。外部画像やスクリプトを必要としません。

## Windowsで採点付きアプリを使う

1. プロジェクト直下の `Start-Learning.cmd` をダブルクリックします。
2. ChromeまたはEdgeで **http://127.0.0.1:4180/** を開きます。
3. 「テキスト」「問題集」「用語」を利用します。「設定」で教材を保存すると、同じブラウザーでのオフライン動作を確認できます。
4. 終了するときは起動した画面でCtrl+Cを押します。

現在のPCでは付属Node.jsを使います。別のPCではNode.js 22以降が必要です。アプリを実行するだけなら依存パッケージの再インストールは不要です。`dist/index.html` のダブルクリックではPWAは動きません。

アプリ内の「模擬試験」は準備中で開始できません。学習履歴はブラウザーに保存され、別のブラウザーやURLとは共有されません。設定でJSONを定期的に書き出してください。

## iPhoneで採点付きアプリを使う

**まだHTTPS公開していません。** Windowsのlocalhost URLをiPhoneで開くことはできません。

1. ソースをGitHubの公開リポジトリの `main` ブランチへ登録します。
2. Settings → Pages → Build and deployment → Source を **GitHub Actions** にします。
3. 同梱ワークフローの完了後、Pagesに表示されたHTTPS URLをiPhoneのSafariで開きます。
4. 共有 → 「ホーム画面に追加」を選びます。
5. ホーム画面のアイコンからオンラインで起動し、設定 → 「教材を保存・オフライン状態を確認」を実行します。
6. 準備完了後、機内モードでアプリを終了・再起動し、未閲覧の教材・問題を開きます。

公開先アカウント・リポジトリへの接続と、iPhone実機受入は残作業です。確認項目は `docs/IPHONE_CHECK.md` にあります。
