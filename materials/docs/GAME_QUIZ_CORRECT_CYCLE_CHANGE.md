# 正解するまで同じ巡の出題候補に残す変更

対応日：2026-10-09。[前回の一巡出題](GAME_QUIZ_CYCLE_CHANGE.md)への追加依頼に対応。

## 現在の仕様

- 知識の間250問は、現在の巡で未正解の問題からランダムに抽選する。
- 表示・誤答・未回答ではフラグを付けない。正解時だけ正解済みフラグを付け、同じ巡の候補から除外する。
- 全250問に正解した後、次の問題を出す際にフラグをリセットする。画面には「出題 n巡目・正解済み x / 250問」を表示する。
- 同じ部屋では別の未正解問題を優先する。未正解が1問だけの場合は、1問目を間違えたら2問目もその問題を出す。正解したら次の巡に進み、別の問題を選ぶ。
- 同じ問題を同じ部屋で再回答しても、誤答と正解の両方を学習履歴に保存する。再読み込みによる重複記録はしない。
- 「はじめから」・再読み込み・冒険バックアップでも正解済みフラグを引き継ぐ。誤答時のHP減少・報酬の判定は維持する。学習室の個別練習・65問評価は今回の対象外。

## 旧保存との互換性

`quizCycle.mode: "correct"` により新方式を識別する。旧方式の表示済みフラグは正解の証拠ではないため正解済みへ転用せず、1巡目から開始する。保存中の部屋に残る正解回答だけ回収する。それ以前の正誤は推測しない。冒険・HP・コイン・学習室の回答履歴は維持する。新方式のバックアップはその時点の巡と正解済みフラグを復元する。

教材追加IDは未正解、削除IDは対象外にする。同じIDの本文改訂は同じ問題として扱う。進行中の冒険は開始時の教材を維持する。
