## レビュー対応表

| ID | 対応内容 | 受入条件の確認 |
|---|---|---|
| GQR-001 | 練習終了時に、未確定の下書きを含む全問を同じ回答内容で採点・履歴保存する。選択数不足・未回答は不正解として記録し、画面に扱いを明記。確定済みの記録・回答日時は維持する。一覧からの「保存した学習を終了する」も同じ処理を通す。 | 1問の正解下書き、途中の未確定問題、複数選択の不足、未回答、再開、終了後の再保存を検証。結果と履修数・初回/直近成績が同じ記録に基づき、終了・再保存で回答回数を増やさない。 |
| GQR-002 | 受験IDの一意性、完了した受験の65問の記録・連番キー・問題IDの一意性・回答日時、未提出受験に提出記録がないこと、所属受験のない評価記録を検査。保存中の評価セッションは受験版・開始日時・提出/終了状態と照合し、提出済みなら各問題の版を含むスナップショット全体と選択集合も照合する。検証後にのみ保存する。 | 全記録削除、1問欠落、受験ID重複、問題版・本文・選択の不一致、時刻・提出状態の矛盾、終了後の欠落を拒否。拒否時に元の保存値を上書きしないことを検証。途中・提出済み・終了後・再受験・旧教材版の正規バックアップを復元できる。 |

主な実装：[study-state.mjs](../public/tower/study-state.mjs)、[study-ui.mjs](../public/tower/study-ui.mjs)。回帰検証：[study.test.mjs](../tests/study.test.mjs)、[study-browser-check.mjs](../scripts/study-browser-check.mjs)。

## 保存形式と検査の範囲

- schema 1を維持。現在の教材との一致は要求せず、保存された当時の問題と回答を照合する。既存の提出済み評価に残る未確定フラグも許容する。JSONのオブジェクト項目順・選択集合の順序は同値として扱う。
- セッション終了後の受験は、現形式で残る受験ID・終了日時と65件の記録の所属、欠落、重複を検査する。破棄済みのセッションの問題配列と照合することはできない。整合した手作りデータや未読自己申告を保証する機能ではない。
- 練習で未回答のまま終了した問題も「回答済み」の不正解記録になり、直近の誤答から復習できる。履修数は理解度や合格認定を表さない。
- 旧実装で終了済みの練習の欠落履歴を推測して自動補填はしない。本修正後に終了する練習から統一した処理を適用する。
