# ゲーム内クイズを一巡する出題方式

対応日：2026-10-08。依頼：全問題を満遍なく出し、一度出た問題は次から出づらくし、全問出題後にリセットする。

## 変更後の動作

- 「知識の間」の出題対象250問について、現在の一巡で未出題の問題から等確率で抽選する。全問が出るまでは出題済み問題を再抽選しない。
- 出題フラグは回答の正誤ではなく、問題を表示する段階で付ける。部屋へ入ると1問目、「次の問題へ」で2問目を出題済みにする。1問目で力尽きた場合や途中で冒険をやり直した場合、未表示の2問目は未出題のまま。
- 全問を出題した後、次の問題を出すときにフラグをリセットして次の一巡へ進む。一巡の境界でも同じ部屋の2問は重複させない。
- 画面に「出題 n巡目・x / 250問」を表示。「はじめから」で新しい冒険を開始しても出題履歴を引き継ぐ。
- 学習室の個別練習・誤答復習・65問評価は、利用者が選ぶ学習範囲と評価セットを維持する。本変更の抽選対象はランダムなクイズ部屋の250問であり、複数選択などを含む学習室全333問への出題形式変更ではない。

## 保存・教材更新

冒険の保存データに `quizCycle: { round, seen }` を追加。既存の自動保存・冒険バックアップに含める。再読み込みでは同じ問題・選択肢順・出題履歴を復元する。バックアップを読み込むと、そのバックアップ時点の履歴に戻る。ブラウザーの保存データ削除や別端末への未移行時は引き継げない。

旧保存も読込可能。旧版では全出題履歴を保存していないため、保存中の部屋で表示済みの問題だけを回収し、それ以前の出題は推測しない。初回適用時は、この回収分から一巡を開始する。

新しい冒険へ教材を反映する際、引き継いだ問題IDのうち現行の対象外を除外し、追加問題IDは未出題として扱う。同一IDの本文改訂は同じ問題として扱う。進行中の冒険は従来どおり開始時の教材を保持する。出題フラグは学習室の回答成績・理解度とは別の情報。
