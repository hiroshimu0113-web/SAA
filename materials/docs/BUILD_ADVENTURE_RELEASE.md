# 改訂3の冒険：試遊用リリース

対象：card-effects-proposal.html#balance3（改訂3）。30形態/6系統を操作する依頼に基づき、独立試作の戦闘エンジンを通常のゲームから開ける冒険へ接続する。

## 遊び方

- 公開先：`tower/builds.html`。既存の`index.html`および旧ゲームの各URLにも「改訂3の冒険」への入口を表示。
- 開始時は6系統から指定でき、未指定ならランダム。共通5枚＋専用3枚、基本EC2/正常データ/初期保存記録を持つ。初期レリックなし。
- 8階層の戦闘。1階は通信、2〜7階は乱数で選ばれた2種類の妨害から進路を選ぶ。最終ボスはHP72・設備妨害で固定。
- 戦闘後の報酬は3候補/スキップ、無料強化1回、HP14回復。階間に休憩/交換所/知識の間から1つ寄り道できる。
- 休憩は回復22/強化/削除から1操作。交換所はカード35、レリック100、削除45コイン。カードは売切れ管理、レリック/削除は各1回。デッキ最低3枚。
- 知識の間は公開教材から2問。選択肢が解説に切り替わり、誤答ごと最大HPの10%切上げ＝8ダメージ。完答は未所持レリックだけ、1問正解は30コイン。問題本文/正答/解説は選出時に保存し、教材更新後も途中回答を維持。
- レリックは追加2枚ドロー、開始時通信防御8、勝利時HP6、勝利時追加30コインの4種類。名称は既存教材カタログの対応語を使用。
- 扇形手札、長押し/キーボードでカード詳細、割符、役進捗、メニュー内の5列コレクション。詳細は×またはカード背景で閉じる。敵/自分のターンは各0.5秒、HP損失は画面揺れ（視差効果低減に対応）。
- 設備再開/撤去、保存記録からのデータ復元、未完了仕事の再開は設備欄から操作。合法な札/再開/復元/再試行がある間は自動終了しない。任意の撤去だけを理由に自動終了を止めない。

## 実装・保存

- `build-lab-engine.mjs`の30形態の実処理を再利用。試作用比較のエンジン/測定条件は変更しない。
- `build-adventure-engine.mjs`にマップ/寄り道/購入/クイズ/報酬/保存検査、`build-adventure-app.mjs`に画面を実装。
- 保存キー`saa-build-adventure-v1`。旧冒険`saa-tower-run-v1`と独立試作`saa-build-lab-v1`は変更/移行/削除しない。記録の書出し/読込みを装備。古い操作IDの連打は状態リビジョンで拒否。
- カードの教材補足は`export-build-adventure.mjs`で既存正本から30形態分を生成。全カードの独立意味監査を済ませた扱いにはしない。
- Safari14向けに単一HTMLへビルド、オフラインパッケージに含める。CIで新画面のWebKit検証と配信HTML/教材補足のSHA256照合を実施する。

## 試遊の範囲と限界

- 全181形態の一括採用ではない。30形態の効果を通して配置/保留/生成/割引/再開/復元/役を試す。
- 複数の対象は適合する先頭候補へ自動適用。可視性タイムアウトは非表示期限記録までで、競合する受信者は未導入。プレイスメントグループはホスト配置と役の条件を設定するが、ホスト故障の敵は未導入。この2枚の詳細に制限を表示する。
- 全25脅威、正式レア度70/25/5、全レリック、仕事の部分成果UI、旧冒険のゴミ札/デバフ5種の新モード移植は対象外。新モードで未対応なのに動作済みとは表記しない。
- 寄り道と獲得レリックが増えたため、独立試作の完走率を新冒険の勝率として引用しない。6系統×10シードは進行停止/保存再開の検査で、難易度の最終評価ではない。
