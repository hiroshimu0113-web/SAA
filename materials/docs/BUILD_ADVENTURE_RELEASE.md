# 改訂3の冒険：試遊用リリース

対象：card-effects-proposal.html#balance3（改訂3）。30形態/6系統を操作する依頼に基づき、独立試作の戦闘エンジンを通常のゲームから開ける冒険へ接続する。

## 遊び方

- 公開先：`tower/index.html`（通常入口）。`builds.html`と過去の各ゲームURLも同じ改訂3のカードセットへ統一。旧冒険は`legacy.html`から保存記録を継続できる。古いオフラインキャッシュに残っていない新入口`build-colours.html`も用意。
- 開始時は6系統から指定でき、未指定ならランダム。共通5枚＋専用3枚、基本EC2/正常データ/初期保存記録を持つ。初期レリックなし。
- 8階層の戦闘。1階は通信、2〜7階は乱数で選ばれた2経路から進路を選ぶ。このうちランダムな2階には強敵の経路がある。最終ボスはHP72・設備妨害で固定。
- 戦闘後の報酬は3候補/スキップ、無料強化1回、HP14回復。階間に休憩/交換所/知識の間から1つ寄り道できる。
- 休憩は回復22/強化/削除から1操作。交換所はカード35、レリック100、削除45コイン。カードは売切れ管理、レリック/削除は各1回。デッキ最低3枚。
- 知識の間は公開教材から2問。選択肢が解説に切り替わり、誤答ごと最大HPの10%切上げ＝8ダメージ。完答は未所持レリックだけ、1問正解は30コイン。問題本文/正答/解説は選出時に保存し、教材更新後も途中回答を維持。
- レリックは追加2枚ドロー、開始時通信防御8、勝利時HP6、勝利時追加30コインの4種類。名称は既存教材カタログの対応語を使用。
- 扇形手札、長押し/キーボードでカード詳細、割符、役進捗、メニュー内の5列コレクション。詳細は×またはカード背景で閉じる。敵/自分のターンは各0.5秒、HP損失は画面揺れ（視差効果低減に対応）。
- 設備再開/撤去、保存記録からのデータ復元、未完了仕事の再開は設備欄から操作。合法な札/再開/復元/再試行がある間は自動終了しない。任意の撤去だけを理由に自動終了を止めない。

- ユーザーの要望により、丸い顔・笑顔の2頭身SVGから、陰影のある成人風のファンタジー立ち絵へ変更。鎧/外套/フード/装備、緑・青・黄土・紫・銅・青緑の差で6系統を区別する。既存作品のキャラクターは使用していない。
