# 強化・クイズ・デバフ表示の変更

2026-10-07。教材本文・公開範囲は変更せず、ゲームのルールのみ改訂。

## 強化

- 非パワーカードの基本ダメージを1.5倍、小数切り上げ。例：集中処理18→27、負荷分散7→11、再試行3→5。多段攻撃は各ヒットの基本値に適用し、攻撃力やブロック由来の加算部分をさらに1.5倍にはしない。
- デバフ付与量を＋1。炎上は数値と減衰までの長さがともに増加する既存仕様を維持。その他の非パワーのブロック・回復・ドロー等は既存の強化量を維持。
- パワーは効果を据え置き、コスト－1（最低0）。最適化は1→0で攻撃力＋2のまま、冗長構成は2→1で毎ターン3ブロックのまま。
- `cardValues()` を計算の正本とし、古い教材カタログにあるupDamage/upStrength/upArmorより上記ルールを優先する。旧保存の強化済みカードにも新計算を適用。
- 強化前後・詳細・実コスト・行動予測を同じ計算で表示。

## 遅延

通常は1ターン休止、強化された迂回は2ターン休止し、その後2回行動。休止中も2回行動中も再付与不可。休止ターン追加で再発動回数を増やさない。

保存内の従来値1＝1ターン休止、2＝次に2回行動を維持。3以上は残り休止ターン＋1を表す。例：3→1→2→0。表示は内部値ではなく残り休止ターン、2回行動中は「×2」。敵味方とも同じ規則。

## クイズ

新規入室はrulesVersion 2。誤答を確定した時点で最大HPの10％（小数切り上げ）を失う。最大HP72/77なら8、112なら12ダメージ。残HPを超えて負数にはしない。

- 全問正解：未所持レリックのみ。全所持なら追加報酬なし、コイン代替なし。
- 1問正解：完了時30コイン。1回の誤答ダメージは別途適用済み。
- 0問正解：報酬なし。生存して2問完了すれば誤答ダメージ2回分。
- HPが0になった時点で終了。途中で力尽きた場合、1問正解済みでも完了報酬はなく、最後の誤答の正解・解説を表示する。
- 入室時HP・1回のペナルティ・適用済み合計を保存して整合性を検査。再読込・バックアップ復元・二重タップで追加ダメージや報酬の再取得をしない。
- 変更前から保存中のクイズはその部屋だけ従来の採点・報酬で完了。旧完了結果のコインやHPも巻き戻さない。次の新規入室から新ルール。

## コンパクト表示

自分と敵、それぞれのキャラクター下に有効なデバフだけアイコン＋数値を表示。0のものと空の行は非表示。炎上♨・過負荷ϟ・遅延⌛・枯渇▽・設定不備⚙。色だけに頼らずアイコンを分け、読み上げ名とツールチップも設定。長押しで従来どおり詳細を確認可能。
