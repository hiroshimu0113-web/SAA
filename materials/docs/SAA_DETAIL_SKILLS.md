# 再レビュー：詳細スキルの学習先

2026-10-08 JST。NR-004で指摘された[公式分野4](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03-domain4.html)の「Skills in」28項目を、本文・確認方法へ対応させた。公式文章の転載ではなく、学習時の短い索引である。旧対応表の14タスクに、この粒度の索引を補う。

これは学習先の存在を作成者が確認した表であり、全主張の独立監査や本人の理解完了を示さない。分野1〜3の全詳細スキル、分野4の「Knowledge of」に列挙された全製品の網羅表ではない。Outposts等の製品例を含む網羅性の監査は未実施。試験対象サービス名の暗記を完了条件にはしない。

本文はアプリの「テキスト」で下記タイトルを検索できる。通常問題は章で絞り込める。assessmentの問題・解説を先に読むと未読の到達度確認ではなくなるため、先に本文内の確認問答または通常問題を使う。
