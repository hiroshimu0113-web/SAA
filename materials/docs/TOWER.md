# クラウドの尖塔：独立ゲーム
2026-10-06。ユーザーの指示により、教材の学習・読了とは独立したデッキ構築型の冒険を開発。
## 今回の範囲
- 20カード（攻撃、スキル、持続効果）、初期10枚、3エナジー、5枚ドロー。
- 8階で各階のルートを選択。通常敵6種類、強敵、最終ボス。
- 敵の行動予告、ブロック、強化、弱体、除外、山札の再構成。
- 勝利報酬の3択とスキップ、休息／アップグレード、カード購入／削除、2問クイズ、4遺物。
- HPを持ち越し、敗北でラン終了。次のランは初期デッキから。
- 専用localStorageキー saa-tower-run-v1。教材の保存データと分離。各操作で保存し、バックアップの書き出し・検証後読み込みに対応。
- 独立入口 public/tower/index.html。既存の設計クエストは保持。
- 最新指示により?マスでAWSクイズを出題。学習記録は教材と分離。カード名はクラウド運用モチーフだが、効果・数値は架空。Slay the Spireの画像・音声・固有キャラクターは使用しない。
## ルール
毎ターン残った手札を捨て、予告された敵行動を解決。敵ブロックは次の敵行動直前に消滅。弱体は敵行動後に1減少。自分のブロックは次の自分のターン開始時に消え、持続防御を付与。山札が空なら捨て札を混ぜ、最大10枚まで引く。使用中のドローカードも捨て札に入れてからドロー。持続・除外カードはその戦闘中は山札へ戻らず、次の戦闘では復帰。自傷でHP0になれば敵を同時に倒しても敗北。
強敵勝利で未所持の遺物を獲得。全遺物所持済みなら30コイン。通常勝利22コイン、強敵40コイン。休息22HP、購入35コイン、削除45コイン。削除後も最低5枚。
## 制限
第1幕相当の縦切り実装。複数キャラクター・複数幕・長期アンロック・音声・複数敵同時戦闘は未実装。複数階の分岐は各階で合流する。iPhone実機での操作感・難易度の継続評価は別途。
